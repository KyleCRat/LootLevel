# LootLevel

An in-game item-level reference table for comparing rewards across content
and seasons. Select an expansion and season layer to view its reference data.

Open or close the table with `/lootlevel` or `/ll`. The window supports
moving, scaling, and item tooltips.

## Commands

| Command | Action |
| --- | --- |
| `/ll show` / `/ll hide` | Show or hide the table |
| `/ll lock` / `/ll unlock` | Lock or unlock its position |
| `/ll reset` | Reset the position |
| `/ll layer list` | List season layers |
| `/ll layerset list` | List expansion layer sets |
| `/ll help` | Show command help |

For data contributors, `/ll collector` opens the bonus-ID collector.
Reference data is bundled with the addon, not a live guarantee of every reward.

Supports Retail WoW 12.1.5.
